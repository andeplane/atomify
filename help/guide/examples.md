# Use the example library

Atomify comes with more than 50 ready-to-run examples, from simple Lennard-Jones fluids to water, silica, carbon nanotubes, granular flows and reactive force fields. See the [list of bundled examples](/reference/bundled-examples).

## Find examples

- **Example library** in the sidebar shows every example as a card with a picture and description.
- The sidebar's **Examples** list shows every example by name.
- Home shows four of them under **Start from an example**.
- **New project → From example** has a search box that filters by title, description and keyword.

![The Example library](/screenshots/example-library.webp)

## Quick run or Use as project

Each example offers two things:

- **Quick run** (the ▶ button) runs it right away as a temporary run, to see what it does. See [Quick runs](/guide/quick-runs).
- **Use as project** copies its files into a new project, where you can edit and run it as often as you like. In the sidebar list, click the example's name.

Quick run is disabled until the engine has loaded.

## Examples with notebooks

Some examples ship their own analysis notebook, which opens when you click **Analyze in notebook** in a project made from them.

## Your own library

You can load a different library from a link: see [Load a custom library](/guide/custom-library) and [Tutorial 6](/tutorials/example-library).
