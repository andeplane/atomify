# Quick runs

A **quick run** starts an example immediately, without creating a project. It's the fastest way to see what an example does.

## Start a quick run

Any of these:

- **Quick-run an example** on Home (runs the first example in the library).
- The ▶ button on an example card on Home or in the **Example library**.
- The ▶ button next to an example in the sidebar's **Examples** list.

The buttons are disabled until the engine has loaded.

![A quick run](/screenshots/quick-run-live.webp)

## What's different about a quick run

The run screen shows a banner: **This is a quick run — files are temporary and will be discarded.**

- Its files live only in memory. Reloading or closing the tab discards it.
- It has no Notebook tab and no project menu.
- Otherwise everything works: the 3D view, analysis, plots, coloring, slicing, and running it again.

## Keep it: Save as project

Click **Save as project** in the banner. Atomify creates a real project with the example's name, copies its files and the runs you made, and opens it.

![A completed quick run](/screenshots/quick-run-completed.webp)

To start editing an example right away instead, use **Use as project**, which creates the project without running anything.
