# Keyboard and mouse

## During a run

These work on the run screen while a simulation is live. They're ignored while you type in a field or when a button has keyboard focus: click the 3D view first.

| Key                         | Action                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------- |
| <kbd>Space</kbd>            | Pause or resume the simulation.                                                             |
| <kbd>1</kbd> … <kbd>9</kbd> | Set the simulation speed to 1, 2, 4, 6, 10, 20, 50, 100 or 200 timesteps per screen update. |
| <kbd>C</kbd>                | Copy the camera position and target as `#/camera` directives to the clipboard.              |
| <kbd>P</kbd>                | Toggle pan mode: left-drag pans instead of rotating.                                        |
| <kbd>Esc</kbd>              | Clear the atom selection; leave full screen.                                                |

## Camera

| Input                                               | Action                            |
| --------------------------------------------------- | --------------------------------- |
| Left-drag                                           | Rotate (pan, in pan mode)         |
| Right-drag                                          | Pan                               |
| Scroll                                              | Zoom towards the pointer          |
| One-finger drag (touch)                             | Rotate                            |
| Pinch (touch)                                       | Zoom and pan                      |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Turn the camera (3D view focused) |
| <kbd>W</kbd> / <kbd>S</kbd>                         | Move forward / back               |
| <kbd>A</kbd> / <kbd>D</kbd>                         | Move left / right                 |
| <kbd>E</kbd> / <kbd>Q</kbd>                         | Move up / down                    |
| <kbd>Shift</kbd> + movement keys                    | Three times faster                |

## Selecting atoms

| Input                    | Action                              |
| ------------------------ | ----------------------------------- |
| Click an atom            | Select it (click again to deselect) |
| <kbd>Shift</kbd> + click | Add to or remove from the selection |
| <kbd>Esc</kbd>           | Clear the selection                 |

## Editor

| Key                                                      | Action                                   |
| -------------------------------------------------------- | ---------------------------------------- |
| <kbd>Ctrl</kbd> <kbd>S</kbd> / <kbd>⌘</kbd> <kbd>S</kbd> | Save now (edits also save automatically) |
| <kbd>Ctrl</kbd> <kbd>F</kbd> / <kbd>⌘</kbd> <kbd>F</kbd> | Find                                     |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> / <kbd>⌘</kbd> <kbd>Z</kbd> | Undo                                     |

The editor is Monaco, the editor from VS Code, so its usual shortcuts work, including multiple cursors (<kbd>Alt</kbd>-click) and <kbd>F1</kbd> for the command palette.
