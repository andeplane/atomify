# Getting help

## Read the docs

Search this site with <kbd>/</kbd> or <kbd>Ctrl</kbd> <kbd>K</kbd>. [Troubleshooting](/faq/troubleshooting) covers the most common problems, and the [FAQ](/faq/) the most common questions. For LAMMPS commands themselves, the [LAMMPS manual](https://docs.lammps.org/) is the reference.

## About Atomify

Click **About** at the bottom of the sidebar for the source code, the author and ways to get help.

![The About dialog](/screenshots/about.webp)

## Report a bug or ask a question

Open an issue on GitHub: [github.com/andeplane/atomify/issues](https://github.com/andeplane/atomify/issues). You can also email andershaf@gmail.com.

A good bug report includes:

1. **Your browser and its version**, and your operating system.
2. **What you did**, step by step, and what you expected.
3. **What happened instead**: the error message, and the console output of the run (copy it from `log.lammps`).
4. **The script.** Attach the project zip (**⋯ → Download project**) if you can.

## Contribute

Atomify is open source. Improvements to the app, new examples and fixes to these docs are welcome: every page has a **Suggest a change to this page** link at the bottom.
